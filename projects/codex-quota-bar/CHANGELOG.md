# Changelog

## 0.6.0 / Build 18 — 2026-10-23

- 触发：用户改为通过 OpenCodex 管理多账户，需要手动选择额度栏监控对象。
- 唯一数据源切换为 `ocx account list openai --quota --refresh --json`，由 CLI 负责认证和服务发现，不再启动官方 app-server。
- 新增「监控账户」子菜单；首次选择当前账户，之后保存明确账户 ID。选择不修改 OpenCodex 实际使用账户；移除已选账户时提示重新选择。
- 使用返回的短/周/月窗口，转换已用比例为剩余比例；缺失窗口显示暂无数据。CLI 未提供的 Credits / 重置券详情不再显示。
- 趋势按账户 ID 的摘要文件名隔离；旧 CSV 原样保留，不自动归属。`__main__` 按主账户槽位处理，替换登录身份前需备份并移出旧槽位 CSV。
- 加入子进程读取期限和输出限制，明确失败/缓存提示；失败缓存不作为新趋势样本写入。
- 验证：用户已在 Mac 的 OpenCodex 2.90.0 上验证查询命令；本次代码在 Linux 开发，原生编译、签名和离线回归由 macOS CI 检查，结果随 PR 更新。本机新版安装、账户切换、曲线和深浅外观待实机验收。

## 0.5.6

- 趋势折线跨越重置、长采样间隔和缺失值时仍保持连接；重置点保留空心圆，不再把线段拆开。
- 悬停提示改为图内横向定位：移入图表绘图区后出现竖向定位线和双窗口采样点；按横向最近的采样记录同时显示两个额度值，不做中间值插算，并明确标注重置判断。

## 0.5.5

- 趋势图悬停提示改为当前横轴记录的时间、两种额度窗口的剩余/已用比例；重置信息仅显示当前点对应的窗口，不再把整段历史重置事件误当作当前点数据。
- 长采集空档按额度窗口分别判断：若该窗口的已记录值保持不变则水平接续；值有变化或缺失时才保留断口，避免无关窗口把折线切断。

## 0.5.4

- 加强密集采样下的曲线平滑：在连续数据段内按屏幕距离做局部加权平滑，再用保形曲线绘制；保留区段端点，不跨重置、缺失数据或长时间断档。

## 0.5.3

- 趋势曲线改用保形平滑，保留采样点与峰谷，不跨额度重置、缺失数据或长时间断档连接。

## 0.5.2

- 趋势图下方显示 5 小时与 7 天窗口各自的上一次重置时间；由服务端下一次重置时刻减去窗口周期计算，不依赖趋势记录是否完整。

## 0.5.1

- 图表增加周期标题和蓝紫图例，明确变化点数量，并细化曲线与重置标记。

## 0.5.0

- 趋势图去掉面积色带和重复图例，只留蓝紫折线、末端圆点和重置空心圆。

## 0.4.3

## 0.4.2

## 0.4.1
