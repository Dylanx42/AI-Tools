# Changelog

## 0.3.1

- 将趋势入口改为菜单内原生折线图，不再跳转外部表格应用。
- 同时展示 5 小时与 7 天剩余额度曲线、当前值、记录数和起止时间。
- 图表使用 macOS 语义色，自动适配深色与浅色外观。
- 禁止多实例运行，并在落盘前复核最新记录，避免重复趋势点。

## 0.3.0

- 新增本地 CSV 使用趋势：首次成功读取建立基线，后续只在额度窗口数据变化时追加记录。
- 菜单新增趋势记录入口，可直接打开 `quota-history.csv`。
- 趋势文件仅包含时间、百分比、窗口长度和重置时间，不保存账号、Token 或完整额度响应。

## 0.2.1

- 修复从 Finder 或登录项启动时，npm 安装的 Codex CLI 因 PATH 中找不到 Node 而无法读取额度的问题。
- JSON-RPC 客户端版本改为自动读取 App 的版本号，避免发布版本不一致。

## 0.2.0

- 加入智能刷新：变化/阈值 30 秒，短期稳定 60 秒，持续稳定 2 分钟。
- 加入低电量降频和失败退避。
- Mac 唤醒后立即刷新；菜单打开且数据偏旧时立即刷新。
- 保持原有菜单栏显示布局不变。

## 0.1.0

- 首个本地版本。
- 通过 `codex app-server` 读取 5 小时与 7 天额度窗口。
- 显示套餐、Credits、重置券数量和精确重置时间。
