# Privacy

Codex 额度栏是本地菜单栏工具。0.6.0 起只通过本机 OpenCodex CLI 查询账户与额度。

## 读取的数据

执行 `ocx account list openai --quota --refresh --json`，解析账户 ID、展示名称（包括 OpenCodex 按其隐私设置返回的邮箱）、套餐、当前账户标记、短/周/月额度窗口、重置时间、暂停/需重新登录和刷新状态。

这些数据在内存中用于账户选择和额度展示。只显示实际返回的窗口，不推算缺失额度。查询会更新 OpenCodex 自身的额度缓存；认证和与上游通信由用户安装的 OpenCodex 处理。

## 不读取的数据

- 浏览器 Cookie、历史记录或本地存储。
- `~/.codex/auth.json`、OpenCodex 账户凭据文件、管理令牌文件或 Keychain 的内容。
- Codex 对话、提示词、项目文件和会话日志。

额度栏不调用账户切换、登录、删除、额度激活、重置券兑换或模型推理命令。OpenCodex CLI 使用自己的认证机制，本工具不索取、复制或保存其令牌。

## 存储与传输

- 使用系统应用偏好保存选中的账户 ID，不保存邮箱或账户展示名称。
- 每个账户在 `~/Library/Application Support/CodexQuotaBar/opencodex-accounts/` 单独保存 CSV，文件名使用账户 ID 的 SHA-256。摘要用于文件命名，不是匿名化保证。
- CSV 只记录读取时间、额度百分比、窗口长度和重置时间；失败/明确过期缓存不会作为新采样写入。文件创建权限为 `0600`、账户目录为 `0700`。
- 不持久化完整 CLI 响应，不输出原始 stderr，不上传遥测或连接自有服务器。额度查询所需网络行为由 OpenCodex CLI / 服务完成。
- 旧版 `quota-history.csv` 保留原样，不自动归属到某个账户。备份趋势时请同时备份旧文件和新账户目录。

`__main__` 是主账户槽位 ID；替换该槽位登录身份前，应先备份并移出对应 CSV，避免不同登录身份共用该槽位历史。
