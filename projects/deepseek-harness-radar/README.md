## 文件结构

## 维护原则

- 只观察、搜索、阅读公开信息和记录。
- 不安装、下载、运行或接入任何第三方 DSH 插件。
- 不修改用户本地 DSH 环境。
- 每次先读 `RADAR.md` 与最近 7–14 天历史，再做增量搜索。
- 只有判断发生实质变化时才改 `RADAR.md`；每日增量写入当月 history 文件。
- Stars/收录排名只用于发现候选，不作为质量结论。
- **研究与记录分层**：GitHub Radar 负责保留详细证据、时间线、版本边界、复现环境、相反证据与长期判断；聊天通知只做结论层压缩，避免把 GitHub 细节重复铺一遍。
