# IP 快捷设置

一个原生 macOS 菜单栏工具，适合需要在多个现场网络之间切换 IPv4 的场景。点击菜单栏的网络图标，选择网络服务即可查看当前 IPv4、切换 DHCP 或填写静态 IP、子网掩码及路由器。静态配置填写保存名称后，可在同一网络服务下快速重用或删除。

## 使用

1. 打开 `IP 快捷设置.app`，点击屏幕右上方的网络图标。
2. 选择 Wi-Fi、有线网卡等网络服务；连接中的地址和配置方式显示在子菜单。
3. 选择“设置静态 IPv4…”或“切换到 DHCP…”。应用时 macOS 会要求管理员授权；取消授权不会执行更改。
4. 在“选择显示的网卡”勾选常用接口；其他接口仍可从“其他网卡”操作，勾选仅影响显示，不会启停系统网卡。默认显示 Wi-Fi 和 USB 10/100/1000 LAN。
5. 默认使用 ⌃⌥⌘I 打开菜单，可在“全局快捷键”中选择 J、K 或关闭。注册失败会提示更换；系统注册检查不能发现所有应用自定义的快捷键冲突。
6. 静态设置中可填写“保存名称”，成功提交后保存在本机。以后在对应网络服务的子菜单选择该配置即可；删除配置不会修改当前网络。

修改网络可能短暂断网，设置成功表示系统命令已完成，不代表网关或业务已连通。静态模式当前要求填写路由器 IPv4；仅显示当前网络位置中有 BSD 接口名称的网络服务，停用服务不可修改，同名服务需要先在系统设置中改为唯一名称。DNS、IPv6 和其他网络设置不由本工具修改。快捷配置以明文保存在当前用户的 macOS 偏好设置中，不上传网络；更换网络位置或删除重建服务后需重新保存。应用不自动设置开机启动。

## 构建

需要 macOS 13 或更新版本及 Apple Command Line Tools：

```sh
./build.sh
open "dist/IP 快捷设置.app"
```

构建产物使用本机临时签名，不是经过 Apple 公证的发行版；换机器使用时可能需要通过系统设置允许打开。构建和签名校验：

```sh
plutil -lint Info.plist
./build.sh
codesign --verify --deep --strict --verbose=2 "dist/IP 快捷设置.app"
"dist/IP 快捷设置.app/Contents/MacOS/IPSwitcher" --self-check
```
