# IP 快捷设置

一个原生 macOS 菜单栏工具，适合需要在多个现场网络之间切换 IPv4 的场景。点击菜单栏的网络图标，选择网络服务即可查看当前 IPv4、切换 DHCP 或设置静态 IPv4。网关可留空，适合直连交换机、防火墙等场景。

## 使用

1. 打开 `IP 快捷设置.app`，点击屏幕右上方的网络图标。
2. 选择 Wi-Fi、有线网卡等网络服务；连接中的地址和配置方式显示在子菜单。
3. 选择“设置静态 IPv4…”并填写 IP 地址和子网掩码。网关留空时，macOS 将清除该服务原有的 IPv4 网关。也可选择“切换到 DHCP…”。应用时按 macOS 提示授权。
4. 在“选择显示的网卡”勾选常用接口；其他接口仍可从“其他网卡”操作，勾选仅影响显示，不会启停系统网卡。默认显示 Wi-Fi 和 USB 10/100/1000 LAN。
5. 默认使用 ⌃⌥⌘I 打开菜单，可在“全局快捷键”中选择 J、K 或关闭。注册失败会提示更换；系统注册检查不能发现所有应用自定义的快捷键冲突。
6. 静态设置中可填写“保存名称”。以后从该网卡的子菜单应用预设时，会按原值设置网关，空网关也能保存和复用。
7. 网卡的 IPv4 配置改动后，子菜单会出现“恢复上一次 IPv4 配置…”。例如从无网关的静态 IPv4 切到 DHCP 后，可用它恢复原来的地址、掩码和网关状态。

切换模式时网络可能短暂中断。菜单中的“当前 IPv4”反映运行状态，DHCP 取得租约需要链路对端提供服务。应用通过 macOS System Configuration 写入当前网络位置下选定服务的 IPv4 配置。上一次配置按网络位置和服务保存在本机，包含该服务原先的 IPv4 参数。命名预设和恢复记录使用本机用户偏好设置保存。

## 构建

需要 macOS 13 或更新版本及 Apple Command Line Tools：

```sh
./build.sh
open "dist/IP 快捷设置.app"
```

构建产物使用本机临时签名，不是经过 Apple 公证的发行版；换机器使用时可能需要通过系统设置允许打开。构建和签名校验：

```sh
plutil -lint Info.plist
./build.sh
codesign --verify --deep --strict --verbose=2 "dist/IP 快捷设置.app"
"dist/IP 快捷设置.app/Contents/MacOS/IPSwitcher" --self-check
```
