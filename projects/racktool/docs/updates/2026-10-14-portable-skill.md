# 2026-10-14：独立 Skill 包与验收流程

## 触发和变化

用户需要在 Codex / WorkBuddy / TRAE 测试工具，并希望免去本地同步 monorepo。
旧 Skill ZIP 只有说明、开发安装器指向源码，不能独立运行。新构建器打包同一份
RackCore/CLI/Profile 和固定版本纯 Python 依赖；提供 runner、保留已有安装的安装器、
安装/更新/回滚文档与三层本地验收规范。Core 行为及数据库格式没有改变。

用户安装新 ZIP 后无需 clone/pull、pip 或 GUI，但需 Python 3.11+ 和 Agent 本地脚本能力。
独立包版本固定；更新 main 不会更新已安装的包。旧开发安装方式仍保留。
业务原图、副本、SQLite 与备份存放在技能目录之外，升级/卸载不删除业务状态。

## 验证与交付

云端 Linux / Python 3.12 完整回归含已有真实私有 Golden，Ruff 和 strict mypy 通过。
独立包在带空格临时目录、`python -S` 下运行，Core 和依赖来自包内，PyYAML 不含原生扩展；
安装完整性、重复安装保留、损坏/缺失/额外文件拒绝、36 个空柜、新建编辑和冲突拒绝通过。
公开回归还覆盖两种 U 方向的绑定副本新增/改名/移动与原版面部件保留。

独立测试包在用户新上传的私有机柜图上通过：59 柜、51 设备、22 个 ascending 柜，
原版面/标准版面方向一致，2 种方向各新增、改名、移动共 6 次提交，2 次冲突拒绝，
预览不改变文件/数据库，原图 Hash 不变。结果只保存在 Git 忽略的私有目录。
最终干净提交的交付包重复核验并保留私有验收摘要。

本轮以会话附件交付版本化 ZIP、SHA256 和 Markdown；文档/脚本经 GitHub PR 保存。
GitHub API 直连受当前环境访问策略限制，连接器未提供 Release 创建/上传接口，
因此本轮没有发布 Release，不把仓库源 ZIP 或未发布 URL 当成独立包下载链接。
