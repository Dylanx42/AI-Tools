## 统一后的说明

- 同一 SQLite 项目绑定的同一 XLSX 内，源、目标机柜均已识别时可跨 Sheet 移动。
  `sync move` 保持原 U 高度；`sync edit`、对话 edit 和位置表回导支持显式改高/改名。
  位置不变的纯改名继续复用 rename 规划。
- 支持仍受占用、越界、设备区宽度/相对列位置、元数据和对象保真检查约束；不允许跨 XLSX/
  跨独立项目迁移，不支持互占源区域的批量换位或任意 Shape 编辑。含不支持对象的夹具拒绝
  位置/高度编辑，不能推导成“所有跨 Sheet 移动都不支持”。
- 本地主导源码实现、调试、回归与实际 Agent 调用，云端只接明确委派；GitHub 保存正式主线，
  Actions 执行自动检查和正式包构建。普通安装只下载完整 Release，源码开发使用 checkout/.venv。
- 本机 Codex 的合成调用/新会话恢复验收按 2026-10-30 记录为 PASS；真实图、Windows 实机和
  Excel/WPS 继续暂缓，其他 Agent 与自动发现机制也未因此获得通过结论。

能力明确指向扩展它们的 ADR-016，ADR 索引补齐 015/016。Phase 0、调研、旧门禁和提示词
保留原时期的结果及上下文，添加适用时期或现行规范链接；不改写历史测试数量和人工验收结果。
