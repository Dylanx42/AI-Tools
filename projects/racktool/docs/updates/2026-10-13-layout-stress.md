## 发现并修复

1. 普通 `=` 开头的设备文字移动后变成公式。旧 be766e5 对专门复现用例为 1 failed / 1 passed；
   新实现保留移动前的单元格类型，新加/改名文字显式保存为文本。
2. 巨大越界 U 范围可能在拒绝前枚举大量值。现在先拒绝边界错误，再做范围/占用计算。
3. 新建项目允许存入非法 XML 控制字符，随后导出失败。已引入统一 Core 文字校验，在添加机柜、
   添加/编辑设备和 Safe Sync 输入阶段拒绝非法 XML 字符、无效 Unicode 与超长/空文字。

新增聚焦验证覆盖备注、链接、数据验证、命名区域、空白合并、Profile 忽略的数据、非法文字、
过期/伪造计划、临时验证失败及 SQLite 写入失败的双文件回滚。合法 emoji、符号、TAB、换行
和公式样式文字继续可用。错误时不修改已有项目或工作簿。
