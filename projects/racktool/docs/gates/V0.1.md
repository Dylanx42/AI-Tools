## Known Limitations

- Text in a detected device area remains a candidate; reserved, empty, placeholder, color-semantic,
  front/back, and non-device labels are not silently classified.
- Non-text values inside a device area are retained at lower confidence and require human classification.
- Duplicate rack titles are reported but not auto-corrected.
- Candidate IDs are source-coordinate identifiers and do not satisfy V0.3 move/re-scan identity rules.
- The private rack workbook contains two layouts in one file; the inventory workbook is not a second
  rack-layout workbook.

## Remaining Non-Blocking Source Exceptions

- One inventory location string remains non-standard; the accepted rack-workbook location is 48U.
- One inventory canonical name differs from the rack diagram's preserved display label.
- One warehouse device is intentionally outside rack-diagram synchronization.
- The confirmed Golden cases remain private because the source contains sensitive business data. A public
  sample still requires later sanitization, but public disclosure is not a V0.1 functional requirement.
