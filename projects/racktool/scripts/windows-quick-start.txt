RackTool Windows 便携版

1. 双击 RackTool.exe 启动。不需要安装 Python，也不需要管理员权限。
2. 点击右上角“打开…”，选择要查看的 .xlsx 文件。
3. “总览”查看原表的整体机柜排布；“机柜”查看单柜和 U 位；“设备”搜索或筛选设备。
4. 有异常时进入“异常与冲突”，先按页面提示修正源 Excel，再重新扫描。
5. 需要交付新表时点击“导出表格”，另存为新的 .xlsx；导出包含“机柜图”和“设备位置表”。
6. 确认无误后才点击“同步更改”。同步会保护源文件；失败时不会写入源 Excel。

建议：首次测试先复制一份 Excel，在副本上打开、导出和同步。不要把 RackTool.exe 放进含有中文路径的压缩软件临时目录；
解压到普通文件夹后再运行即可。

数据位置：项目数据库和运行状态保存在 Windows 的 %LOCALAPPDATA%\\RackTool，源 Excel 旁不会生成 .sqlite 文件。
